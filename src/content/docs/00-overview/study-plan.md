> 目标：12 周内具备「能跟客户对话 + 能看懂方案 + 能协助报价跟单」的最低可上手能力。

## 总体节奏

| 阶段 | 周 | 重点 | 对应模块 |
| --- | --- | --- | --- |
| 打地基 | W1–W3 | 岗位认知 + 贸易物流基础 | 00、01 |
| 进行业 | W4–W6 | 货代规则 + 英语术语并行 | 02、06 |
| 练专业 | W7–W9 | 工程物流核心 + 储能赛道 | 03、04 |
| 能产出 | W10–W12 | 商务销售 + 案例沉淀 | 05、07 |

## 逐周计划

| 周 | 学习主题 | 产出 / 检查点 |
| --- | --- | --- |
| W1 | 岗位本质、职业路径、KPI | 能一句话说清岗位在做什么 |
| W2 | Incoterms、物流全链路 | 能背出 FOB / CIF 责任边界 |
| W3 | 单证、付款方式 | 能看懂提单和装箱单 |
| W4 | 货代角色、FCL/LCL、集装箱 | 能说出标准柜尺寸与用途 |
| W5 | 华南港口航线 + 术语表（并行） | 做一张华南港口速查表 |
| W6 | 术语表 + 邮件用语（并行） | 攒 30 个高频英文术语 |
| W7 | Breakbulk、OOG、特种柜 | 能判断货物用什么柜 / 船 |
| W8 | Heavy Lift、绑扎加固 | 看懂一张项目货方案 |
| W9 | 储能柜产品 + 危险品规则 | 能说清 UN3480 / IMDG |
| W10 | 客户开发、展会获客 | 整理 20 个目标客户线索 |
| W11 | 报价构成、报价单模板 | 独立做一份报价单 |
| W12 | 案例复盘 + 全流程 checklist | 输出第一篇项目复盘 |

## 使用建议

- **每周至少 1 篇笔记**，落到对应模块；
- 学完一周就在上表「产出」栏打勾；
- 计划可随实际工作调整优先级（例如风电单多了就提前学 03 的重件部分）。
