「工程物流项目经理」是一个容易让人误会的岗位名。名字里有"项目经理"，但它在中国货运代理 / 物流公司的语境里，**本质是销售 + 业务开发（Business Development）岗**，而不是传统意义上管进度、管排期的项目管理岗。

## 一句话定义

**Project Cargo Manager（工程物流 / 项目货经理）**：面向工程物流（项目货、重大件、特种柜）客户，负责客户开发与维护、方案报价与项目交付的销售型岗位。

## 本模块你将学到

1. 这个岗位的真实工作内容（销售 + BD，而非纯 PM）；
2. 职业发展路径与关键考核指标（KPI）；
3. 整个学习地图的使用方法。
