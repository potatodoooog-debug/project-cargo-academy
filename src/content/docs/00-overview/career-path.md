## 职业发展路径

从招聘说明书（岗位简介）里可以看到一条清晰的成长阶梯：

```
单人操作  →  带团队  →  部门负责人
```

- **单人操作**：自己开发客户、自己跟单，把"从询价到交付"整条链路跑通。
- **带团队**：在某个行业赛道（如储能柜）做出成绩后，组建并带领小团队。
- **部门负责人**：负责一个业务板块 / 区域，管理投入产出。

## 关键考核指标（KPI）

虽然岗位说明书里写的是"底薪 + 项目利润提成 + 绩效奖金（根据每年设定目标）"，但可以反推出真正被考核的东西：

1. **客户开发量**：一年内开发了多少个新客户、进入了几个新行业。
2. **成单量与利润**：项目利润提成直接挂钩，利润是核心。
3. **目标完成度**：每年设定的目标是否完成（决定绩效奖金）。

## 这决定了你的学习优先级

因为是销售型岗位，学习优先级应该是：

1. **先能跟客户对话**：行业常识 + 术语（模块 01、02、06）；
2. **再能做出专业方案**：工程物流专有知识（模块 03、04）；
3. **然后能开发与成交**：销售与报价（模块 05）；
4. **持续沉淀**：案例库与资源（模块 07、08）。

## 小结

把学习重心放在"能带来客户和订单"的能力上：**行业语言 + 专业方案 + 销售成交**，三件事缺一不可。
