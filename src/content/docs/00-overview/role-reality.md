## 岗位名为什么有"项目经理"？

在工程物流 / 项目货（Project Cargo）行业，"项目"指的不是软件项目或工程项目，而是**单票货物运输方案**——比如一台 300 吨的变压器、一组超尺寸的储能柜、一条产线设备的整体搬迁。

这类货物的运输不是标准集装箱"装柜即走"，需要**定制化方案**：路线设计、船期选择、吊装/滚装方式、绑扎加固、报关与目的港交付。负责这些事务、并把它卖给客户、全程跟下来的人，就被称为"项目经理"。

## 实际工作内容

从招聘说明书（岗位简介）里可以提炼出三条核心职责：

1. **维护现有客户群**：留住老客户，持续出单。
2. **开拓新客户 / 新行业**：例如选定"储能柜"这一新兴赛道，通过国内外行业展会认识并开发客户。
3. **跟进公司给的直客**：以国内出口商为主，含贸易公司与工厂。

> 关键词是"维护、开发、跟进"——这是**销售**的语言，不是**排期管理**的语言。

## 一个新人最容易踩的误区

以为这份工作是"做方案、管进度"，把精力全花在学流程上。但岗位的**核心产出是客户与订单**。流程和专业知识是"工具"，客户开发才是"目的"。

## 小结

| 维度 | 内容 |
| --- | --- |
| 岗位本质 | 销售 + 业务开发（BD） |
| 核心产出 | 客户、订单、利润 |
| 专业知识的作用 | 让你能做出方案、报出价、赢得客户信任 |
| 考核重心 | 客户开发量、成单量、项目利润 |

**新人的首要任务：把"销售思维"和"工程物流专业知识"两条线并行学起来。**
