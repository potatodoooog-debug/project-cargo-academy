## 货代是什么

货代（Freight Forwarder）本身**不拥有运力**，而是整合船公司、航空、铁路、拖车、报关等资源，为货主提供"一站式"物流服务，并从中赚取**服务费 + 运价差价**。

## 货代的主要价值

1. **议价能力**：以走量拿到比货主直接订舱更优的运价；
2. **专业整合**：报关、拖车、仓储、单证一站式搞定；
3. **方案能力**：针对复杂货物（如项目货）给出定制化运输方案。

## 一票标准海运出口的操作流程

```
询价 → 报价 → 订舱 → 拖车/装箱 → 报关 → 装船 → 对单/出单 → 收付款 → 目的港跟踪
```

1. **询价（Inquiry）**：客户提供起运港、目的港、货物信息，询问运价；
2. **报价（Quotation）**：货代给出海运费 + 附加费 + 服务费报价；
3. **订舱（Booking）**：向船公司订舱，拿订舱确认；
4. **拖车 / 装箱（Trucking / Loading）**：安排拖车到厂装货或送堆场；
5. **报关（Customs）**：出口申报放行；
6. **装船（On-board）**：上船并取得提单；
7. **对单 / 出单（Docs）**：核对提单信息，出具提单；
8. **收付款（Settlement）**：结算运费；
9. **目的港跟踪（Tracking）**：跟踪到港、清关、交付。

## 关键概念

- **FCL（Full Container Load）**：整箱，一个货主装满一个柜；
- **LCL（Less than Container Load）**：拼箱，多个货主共用一个柜。

> 工程物流里，FCL 与特种柜是常态，LCL 相对少；但概念要分清。
