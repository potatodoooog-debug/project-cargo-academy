岗位工作地在深圳，属于**华南区域**。熟悉华南港口与航线，是报价和方案设计的基本功。

## 华南主要港口

| 港口 | 英文 / 代码 | 特点 |
| --- | --- | --- |
| 深圳盐田港 | Yantian（YTN） | 华南最大集装箱港之一，深水港，欧美航线多。 |
| 深圳蛇口港 | Shekou（SHK） | 深圳西部港区，近珠三角腹地。 |
| 广州南沙港 | Nansha（NSA） | 广州主力港，覆盖珠三角。 |
| 香港港 | Hong Kong（HKG） | 国际中转枢纽，自由港。 |
| 广州黄埔港 | Huangpu | 内河港，近珠三角工厂。 |

## 常见航线

- **美西 / 美东线**：华南出口美国的常规航线；
- **欧洲线**：经苏伊士/好望角到欧洲基本港（汉堡、鹿特丹等）；
- **东南亚线**：近洋航线，航程短、频次高；
- **中东 / 红海线**：储能柜等新能源货物近年热门；
- **澳洲 / 南美 / 非洲线**：项目货常有需求。

## 新人怎么用

1. 客户说"去某某港"，你要能立刻反应出**大概航线、船期、是否需要中转**；
2. 报价时，起运港的选择（盐田 vs 蛇口 vs 南沙）会影响拖车成本和船期；
3. 工程物流常需要**中转港 / 目的港的装卸能力**评估（有没有吊机、能否卸大件）。
