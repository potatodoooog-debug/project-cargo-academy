## 如何使用本学习站

1. **按模块顺序学习**：00 → 01 → 02 是入门必修，06 英语术语贯穿并行，03 → 04 是专业核心，05 是商务成交，07 / 08 持续沉淀。
2. **学一点、补一篇**：每学到一个新知识点，就在对应模块新增一篇 Markdown 并提交，站点会自动更新。
3. **术语对照**：正文中文，括号内附英文术语，逐步积累行业英文能力。

## 迭代约定

本仓库采用「内容即代码」：`src/content/docs/` 下的 Markdown 文件是唯一内容来源，`git push` 后由 GitHub Actions 自动构建部署，无需手工操作。
