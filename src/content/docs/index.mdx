## 如何使用本学习站

1. **新人从这里开始**：[12 周上手计划](00-overview/learning-plan/)
2. **按模块推进**：00 → 01 → 02 入门；06 术语全程并行；03 → 04 专业核心；05 商务成交；07 / 08 持续沉淀。
3. **学一点、补一篇**：新知识点写成 Markdown 并 `git push`，站点自动更新。
4. **术语对照**：正文中文，括号附英文，靠日常攒邮件能力。

## 迭代约定

「内容即代码」：`src/content/docs/` 是唯一教材目录。架构说明见仓库 `DESIGN.md`。  
公开库只放通用岗位知识；真实运价与客户信息放本地私密目录，不要 push。
