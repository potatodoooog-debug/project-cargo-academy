## 件杂与重吊常见船型

| 船型 | 英文 | 核心结构与吊装特征 | 常见适用货物 |
|---|---|---|---|
| **多用途船** | MPP / MPV（Multi-Purpose Vessel） | 兼具散杂舱、可调二层甲板与克令吊，部分舱位也可装集装箱 | 钢构、机械、吨袋、工程车辆、标准/特种件杂拼货 |
| **重吊船** | Heavy Lift Vessel | 船侧配备高吨位重型克令吊；以 BBC Chartering / SAL Heavy Lift 等典型公开船队为例，单吊常见 150–400 吨，双吊联吊（Tandem Lift）可达 500–900 吨以上 | 变压器、反应釜、盾构机主机、大型模块等重大件 |
| **敞口船** | Open Hatch Vessel | 箱型直壁大舱口，几乎无舱口缘下垂遮挡，吊具垂直落位空间大 | 超长管材、纸浆、风电塔筒分段、成套规则设备 |
| **半潜船** | Semi-submersible Vessel | 可通过压载水使开敞主甲板下潜至水面以下，实施浮装浮卸（Float-on / Float-off） | 海工平台、拖轮、驳船等可浮超大型结构，详见 [Breakbulk 与 OOG 基础](./bbk-oog-basics/) |

## 舱口、二层柜与联吊（Tandem Lift）直觉

- **舱口尺寸（Hatch Opening）**：货物要装进舱底（Under Deck）防海水风浪，第一步不是看舱容，而是先核对**舱口长宽是否小于货件包装后尺寸**——下不去舱口就只能改甲板或换船。
- **二层柜（Tweendeck）**：多用途船舱内可拆装或调节高度的中间甲板，用于把重货与怕压货分层隔离、防止堆叠压损；遇到超高重大件时，船方可以把二层甲板板片拆走或移位，腾出通高底舱空间。
- **联吊（Tandem Lift）**：当单件毛重超过单台船吊额定起重量时，由两台相邻船吊同步联动，通过**平衡梁（Spreader Bar）**共吊同一件超重或超长货物。联吊对两台吊机同步精度、吊点偏心、重心（COG）以及**平衡梁与索具自重计入总吊重**要求极高。

## 班轮订舱（Liner）vs 程租（Voyage Charter）

| 对比维度 | 班轮订舱（Liner Booking） | 程租包船（Voyage Charter） |
|---|---|---|
| **标准合同范本** | BIMCO **CONLINEBOOKING** 班轮订舱单（配合船东提单背面条款） | BIMCO **GENCON** 通用程租合同范本 |
| **适用货量** | 拼货、单件或中小批量件杂货（Part Cargo） | 整船或大批量包船、固定航次项目货 |
| **船期与停泊风险归属** | 船东按公开班轮船期靠泊作业，装卸效率主要由船方/班轮条款统筹 | 租家承担约定装卸时间超期风险，靠泊等泊与天气/口岸延误按租约条款切分 |
| **滞期与速遣（Demurrage / Despatch）** | 班轮订舱通常不设常规程租滞期速遣（若租家延误装船另有亏舱或滞期约定） | 明确约定许可装卸时间（Laytime），超时付滞期费，提前完货可能计速遣费 |

## 租船核心时间与费用术语（必背）

- **Laycan（受载期，Laydays and Cancelling Date）**：船东必须在约定起止日期窗口内抵达装港并备妥装货；若船舶在解约日（Cancelling Date）之后才备妥，租家有权行使解约权。
- **NOR（装卸准备就绪通知书，Notice of Readiness）**：船舶抵达装港或约定地点且在物理与法律上做好装卸准备后，船长向租家、发货人或收货人发出的书面通知，是起算装卸时间的关键触发点。
- **Laytime（许可装卸时间）**：租约允许租家免费用于装货与卸货的时间额度（通常按小时或工作日/天气许可工作日计算）。
- **Demurrage（滞期费）**：装卸实际耗时超出许可装卸时间后，租家按约定费率向船东支付的违约赔偿。租船行话 **“Once on demurrage, always on demurrage”**，指船舶一旦进入滞期状态，通常不再扣除原本例外的周末或节假日。
- **Despatch（速遣费）**：在许可装卸时间结束前提前完成装卸时，船东返还给租家的奖金（干散货与程租合同常见，班轮订舱通常不适用）。

## 件杂附加费直觉（W/M 与 HLS / ELS）

衔接 [件杂货询盘与计费](./bbk-inquiry/)：件杂货常见按计费吨 **W/M**（重量吨或体积吨取大）计费，但遇到单件超重或超长时，船东报价结构中常会触发两类核心附加费：

- **HLS（Heavy Lift Surcharge，超重附加费）**：单件毛重超过船东标准基价覆盖的重量门槛时逐档加收；
- **ELS（Extra Length Surcharge，超长附加费）**：单件长度超过船东标准长度门槛时逐档加收。

> 实务提醒：不同船东对 HLS / ELS 的起算吨位与米数门槛不同，本站不列固定费率数字。**询盘与比价阶段必须问清报价是已全包的 All-in 包干价，还是在基础 W/M 运费之上另计 HLS / ELS。**

## 重大件出运必备工程文件与 MWS

高价值重大件或涉及联吊、驳运的项目货，光有常规装箱单不够，通常还需提前准备工程与第三方审签文件：

- **吊装施工方案（Method Statement）**：明确起吊设备/船吊站位、吊具与平衡梁选型、起吊步骤、重心校验与安全余量；
- **积载与系固方案（Stowage & Lashing Plan）**：明确货件落位甲板/舱内位置、垫木负荷摊薄与绑扎受力计算（船上系固遵循 [绑扎加固与公路段](./lashing-and-road/) 中的 CSS Code 逻辑，最终以船东书面批准为准）；
- **MWS（Marine Warranty Surveyor，海事担保检验师）**：通常受货运保险人（Underwriter）委托介入高价值、高风险重大件或联吊项目，独立审核吊装与系固方案并在现场监督签发适航/适拖批准（Certificate of Approval）。未经 MWS 签发批准擅自作业，可能直接影响保单生效。

## 复述

班轮件杂常用 BIMCO CONLINEBOOKING 订舱单，程租包船常用 BIMCO GENCON 合同，两者对船期与滞期风险的分配完全不同。  
Laycan 定受载窗，NOR 触发 Laytime 起算，超时付滞期费（Demurrage），提前完货在程租里可能拿速遣费（Despatch）。  
高风险重大件或联吊常需准备 Method Statement、积载系固图，并由保险方指定的 MWS 现场审签。
