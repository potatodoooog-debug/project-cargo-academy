## 为什么这是本岗的护城河

普通货代默认世界是 **标准集装箱（FCL/LCL）**。  
工程物流项目经理面对的是：**装不进普通柜、或装进去不经济、或必须按项目节点整件运输** 的货。

三类高频词：

| 术语 | 英文 | 一句话 |
|---|---|---|
| 散杂货 / 件杂 | Breakbulk (BBK) | 不装标准柜、按件装船的货 |
| 超限货 | OOG (Out of Gauge) | 超过标准柜可装尺寸/需特种柜或特殊积载 |
| 重大件 | Heavy Lift / Project Cargo | 重量或尺寸突出，要特殊吊装、绑扎、运输方案的项目型货物 |

实务里三个词常混用，沟通时**先问尺寸三边 + 重量 + 是否可拆**，再贴标签。

## 标准柜装不下时的主要出路

```
货物尺寸/重量
    │
    ├─ 仍可用特种柜 ──► Flat Rack / Open Top / Platform 等
    │
    ├─ 必须打件杂船 ──► Breakbulk / 多用途船 / 重吊船
    │
    ├─ 可滚动上船 ──► Ro-Ro（滚装，适合带轮或可拖滚设备）
    │
    └─ 极端重大件 ──► 半潜船 / 特殊驳运（项目级，协作多）
```

## Breakbulk 直觉

- **船：** 多用途船（MPP）、重吊船、部分杂货船；船上有吊机（Lo-Lo: Lift-on/Lift-off）很常见。
- **货：** 机械设备、钢构、风电叶片/塔筒分段、轨道车辆、预制模块、部分工程车辆等。
- **特点：** 靠**积载图（stowage plan）+ 绑扎方案**吃饭；港作、天气、潮汐、重件许可都会影响节点。
- **对销售的含义：** 你卖的不是「一个柜位」，而是「一套可执行的项目方案 + 风险说明」。

## OOG 直觉

常见触发（数字是数量级直觉，**不是**全球统一法定值；接单以船公司/船图为准）：

- 超长、超宽、超高，导致无法关 20/40 普柜门或超过箱体结构限制
- 单件过重，超过普通柜/普通吊具舒适区
- 形状异形，重心偏移

OOG 仍可能走**集装箱体系**（框架柜等）+ 收取 OOG 附加费；也可能被船东拒绝，改打散杂。

## 接询价时的最低数据清单（背下来）

1. 品名与材质（是否危险品 / 是否带油带电）  
2. **件数**、是否可叠、是否可拆  
3. 每件 **L × W × H（含包装）**、**毛重**、**重心位置**（若有）  
4. 包装形式：裸装 / 托盘 / 木箱 / 框架  
5. 起运地（工厂地址）→ 装港；目的港 → 最终工地  
6. 时间窗：齐货日、最晚到港/工地日  
7. 是否需要门到门、保险、报关、商检  
8. 图纸或照片（异形件强烈建议要）  

> 缺尺寸重量就报价 = 赌运气。新人阶段：**资料不齐只出「待补充资料的初步思路」，不出死价。**

## 和客户解释时的人话版

- 「这票更像项目货，不是普通柜。我们要先看能不能上框架柜；不行就按件杂船做方案。」
- 「超限不是不能运，是方案、费用、船期都会和普柜不一样，需要船东确认积载。」
- 「为了控制风险，请先提供三边尺寸、毛重和包装照片。」
