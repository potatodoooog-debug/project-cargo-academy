## 方案不是运价单

客户要的是：**在时间与风险可接受的前提下，货怎么到得了。**  
运价是方案的一部分，不是全部。

推荐对外结构（邮件或 PPT 均可）：

```
1. 需求理解复述（尺寸/件重/起讫/时间）
2. 可选路径 A/B（如 FR 柜运 vs 件杂船）
3. 每条路径：船期节奏、主要费用构成、主要风险
4. 必须补充的资料清单
5. 建议路径 + 下一步（谁在什么时间提供什么）
```

## 两条路径对比模板

| 维度 | 方案 A 特种柜 | 方案 B Breakbulk |
|---|---|---|
| 适用 | 略超限、柜源好 | 大件/多件/柜不经济 |
| 周期 | 相对跟班轮 | 看船期窗口，可能等船 |
| 费用结构 | 海运+OOG+特种柜+绑扎… | 海运包干或按计费吨+港作+绑扎… |
| 主要风险 | 柜源、OOG 拒载、超限作业 | 船期、积载变更、港作天气 |
| 资料要求 | 尺寸重量照片 | 更详细的图纸/吊装/积载信息 |

## 风险披露（专业感来源）

主动写明，而不是出事后解释：

- 尺寸以**最终包装后实测**为准，可能导致改方案  
- 危险品/带电/带油未披露将无法出运  
- 船东最终确认权（subject to carrier approval）  
- 目的港政策、查验、滞期风险  

## 练习：5 分钟电梯稿

用 150 字中文向客户说明：  
「为什么这票建议先按框架柜询，同时备份件杂船方案。」

写完贴进自己的 [案例库](../07-case-library/) 练习页。
