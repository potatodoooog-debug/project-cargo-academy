## 为什么销售也要懂绑扎

你也许不亲自打钢索，但你要：

- 在方案里**预留绑扎费用与时间**  
- 听懂操作/船东说的「不可绑」「重心偏」  
- 避免对客户承诺「随便一绑就走」  

绑扎英文常见：**Lashing & Securing**；规范讨论里会听到 CSS 代码、索具、马鞍（cradle）、垫木（dunnage）等。

## 三个物理直觉

1. **重心（COG）** — 偏了，吊装和绑扎都危险；要图纸或实测  
2. **受力点** — 货物上要有可绑位置；禁止只绑在脆弱附件上  
3. **加速度** — 海上横摇/公路急刹会放大力；「看起来稳」不等于「动态稳」  

## 装箱责任看 CTU Code

IMO、国际劳工组织和联合国欧洲经济委员会有一份《货物运输组件装载操作规则》，英文 CTU Code。IMO 的说明页写明它是非强制的操作守则，不是某一个国家的法律。它讨论的是装箱、绑扎由谁负责。船上和码头的绑扎要求另外问船东。中文文本从 UNECE 的 CTU 页面下载；打不开就从 IMO 说明页的相关链接进去。

- [IMO：CTU Code](https://www.imo.org/en/ourwork/safety/pages/ctu-code.aspx)
- [UNECE：CTU Code 文本](https://unece.org/transport/documents/standards/ctu-code)

## 船上系固看 CSS Code

IMO 有一份《货物积载和系固安全操作规则》，英文 CSS Code，大会决议 A.714(17) 通过，后来有修订。说明页写明它是国际标准，对象是船东和经营人：船是否适合这笔货、船上有没有系固设备、货物如何积载和系固。船长对航行安全负责。做计划的人要会用船上的 Cargo Securing Manual。规则全文由 IMO 出版，本站不转载。CTU Code 讨论的是货物运输组件里由谁装箱；CSS Code 讨论的是船上怎么积载、怎么系固。绑扎图以船东书面为准。

- [IMO：CSS Code](https://www.imo.org/en/OurWork/Safety/Pages/CSS-Code.aspx)

## 公路超限的官方线

车货总高从地面超过 4 米、总宽超过 2.55 米、总长超过 18.1 米，是《超限运输车辆行驶公路管理规定》里的超限情形。这是交通运输部令 2016 年第 62 号，2021 年第 12 号作了修订。总质量按轴数另有标准，公报还写了符合国家标准的部分车型如何认定。不可解体的大件运输要办许可。办理步骤以起运地当时的政务系统为准，本页不写。

- [国务院公报 2016 年第 62 号](https://www.gov.cn/gongbao/content/2016/content_5120703.htm)
- [国务院公报 2021 年第 12 号修订](https://www.gov.cn/gongbao/content/2021/content_5643282.htm)

## 厂到港：公路段常被低估

门到门项目货，风险经常在**第一公里**：

| 卡点 | 你要想到 |
|---|---|
| 超长超宽超高车 | 特种拖车、轴线车 |
| 路权 | 通行证、夜间通行、护送车 |
| 桥梁限高限重 | 改线或改拆 |
| 工厂吊装条件 | 有无行车、场地是否够转弯 |
| 时间窗 | 封路审批要提前天数 |

**销售动作：** 拿工厂地址后，尽早问清「以前类似货怎么出的厂」，并让操作/车队预审。

## 多式联运一句话

工程物流常是 **公路 + 海运（+ 铁路/驳船）** 组合。  
你的方案能力 = 把分段责任、费用、风险点串成客户听得懂的一条故事线（尤其 Incoterms 与「谁负责哪一段」）。

## 新人跟单观察清单（跟一次车/一次装货就勾）

- [ ] 吊点/叉车位是否与说的一致  
- [ ] 绑扎耗时与人数  
- [ ] 司机/港口额外收费触发点  
- [ ] 照片是否留存（装前/装后/绑扎后）
