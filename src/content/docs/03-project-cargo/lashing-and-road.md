## 为什么销售也要懂绑扎

你也许不亲自打钢索，但你要：

- 在方案里**预留绑扎费用与时间**  
- 听懂操作/船东说的「不可绑」「重心偏」  
- 避免对客户承诺「随便一绑就走」  

绑扎英文常见：**Lashing & Securing**；规范讨论里会听到 CSS 代码、索具、马鞍（cradle）、垫木（dunnage）等。

## 三个物理直觉

1. **重心（COG）** — 偏了，吊装和绑扎都危险；要图纸或实测  
2. **受力点** — 货物上要有可绑位置；禁止只绑在脆弱附件上  
3. **加速度** — 海上横摇/公路急刹会放大力；「看起来稳」不等于「动态稳」  

## 厂到港：公路段常被低估

门到门项目货，风险经常在**第一公里**：

| 卡点 | 你要想到 |
|---|---|
| 超长超宽超高车 | 特种拖车、轴线车 |
| 路权 | 通行证、夜间通行、护送车 |
| 桥梁限高限重 | 改线或改拆 |
| 工厂吊装条件 | 有无行车、场地是否够转弯 |
| 时间窗 | 封路审批要提前天数 |

**销售动作：** 拿工厂地址后，尽早问清「以前类似货怎么出的厂」，并让操作/车队预审。

## 多式联运一句话

工程物流常是 **公路 + 海运（+ 铁路/驳船）** 组合。  
你的方案能力 = 把分段责任、费用、风险点串成客户听得懂的一条故事线（尤其 Incoterms 与「谁负责哪一段」）。

## 新人跟单观察清单（跟一次车/一次装货就勾）

- [ ] 实际尺寸是否与下单一致  
- [ ] 吊点/叉车位是否与说的一致  
- [ ] 绑扎耗时与人数  
- [ ] 司机/港口额外收费触发点  
- [ ] 照片是否留存（装前/装后/绑扎后）
