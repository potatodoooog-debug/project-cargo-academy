本模块是岗位的**专业护城河**——普通货代销售与工程物流项目经理的分水岭。

## 学习目标

学完本模块的基础篇后，你应能：

1. 听懂 BBK / OOG / Heavy Lift / FR / OT 在说什么；  
2. 在资料不齐时，知道还要问客户什么；  
3. 对「柜运特种柜 vs 件杂船」给出有结构的初步判断；  
4. 向客户用**人话**讲清方案选项与风险，而不是只丢一个运价。
