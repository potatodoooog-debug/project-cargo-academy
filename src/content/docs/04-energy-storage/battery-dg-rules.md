> **学习提示，不是法律意见。** 实操以 IMDG 规则、船东书面要求、报关行/DG 代理最新文本为准。

## 为什么这是红线

锂电池在海运中通常按**危险货物（Dangerous Goods, DG）** 管理。  
资料错、瞒报、漏报的后果包括：拒载、退载、罚款、事故责任——**销售个人承诺不了「先出运再补文件」**。

## 你要混眼熟的代号

| 代号 | 含义（直觉） |
|---|---|
| UN3480 | 锂离子电池（通常单独电池） |
| UN3481 | 锂离子电池安装在设备内或与设备包装在一起 |
| UN3090 / 3091 | 锂金属电池相关（较少见于大型储能，但仍要会认） |
| IMDG | 国际海运危险货物规则 |
| MSDS / SDS | 安全数据表 |
| UN38.3 | 电池运输测试相关要求（常被要求提供报告） |
| SOC | 荷电状态；许多承运人要求低于某百分比才能运 |
| DG Declaration | 危险品申报 |

具体分类、包装说明、是否允许集装箱装运等，**必须由合格 DG 人员/代理确认**。

## 接询价强制问题清单（复制即用）

1. 是否含锂电池？锂离子还是锂金属？  
2. UN 编号？正确运输名称？类别/项别？  
3. 电芯/电池是否已按要求测试（如 UN38.3）？报告能否提供？  
4. SDS 最新版？中英文？  
5. 计划 SOC 是多少？能否按船东要求调整？  
6. 包装是否符合对应包装说明？谁负责打包装/标签？  
7. 起运港/船东是否有额外禁运或需要预审？  
8. 是否有电池单独运、设备分开运的可能方案？  

**资料不齐：只收资料、不承诺船期死价。**

## 空运 vs 海运

大型储能柜几乎走海运/项目货；但样品、小电池、文件快递可能走空运——空运对锂电更严。新人不要默认「和普货一样寄」。

## 与普通 OOG 的叠加

储能柜经常是 **OOG/重件 + DG** 双标签：  
既要尺寸绑扎方案，又要 DG 合规。报价与时效都要按「双流程」排。

## 练习

假装客户微信发来：「柜子下周要出印尼，电池的，你先订舱。」  
用 6 条消息回复（要资料 + 管理期望），不要直接说「好的已订」。
