## 市场与物流话术的连接

| 方向 | 物流侧常关心 | 销售侧常关心 |
|---|---|---|
| 东南亚（东盟） | 港口条件、支线、清关习惯、项目工地内陆 | 展会密、决策相对快、竞争激烈 |
| 中东 | 高温季节、港口拥堵、项目节点 | 大项目、付款与代理网络 |
| 欧洲 | 法规与合规文件、铁路/驳船接转 | 认证门槛高、客户专业 |
| 美国 | 法规复杂、船期与码头、强制要求多 | 进入难、一旦进入粘性可能高 |

岗位附录强调**国内展 + 东盟展**，说明公司近期火力在**东南亚储能出口**。新人应优先混熟：雅加达、曼谷、胡志明、马尼拉、河内等港口与内陆常识（见展会日历）。

## 认证名称（混眼熟即可）

客户侧常提：UN38.3、IEC 相关、UL、CE、当地并网/消防要求等。  
**你的角色：** 知道这些文件会影响「能不能出运/能不能清关/项目能不能收货」，把需求传给客户项目经理和单证，而不是自己签发技术结论。

## 展会转化逻辑（预告模块 05）

```
展会名片 → 48h 内跟进邮件 → 要产品规格与目标港
        → 判断是否含电池 → 要 SDS/UN/尺寸重量
        → 出初步路径建议 → 进入正式询价
```

不要在展台承诺运价；承诺「会后 X 个工作日内给路径建议」。
