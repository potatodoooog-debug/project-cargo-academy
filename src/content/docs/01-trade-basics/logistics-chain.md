一票出口货物通常经历下面这条链路。理解全链路，你才能知道自己在哪个环节提供服务、赚哪段钱。

## 主链路（以海运出口为例）

```
工厂备货 → 拖车/内贸 → 出口报关 → 装船 → 海运 → 目的港清关 → 拖车/配送 → 收货人
```

## 各环节说明

| 环节 | 英文 | 说明 |
| --- | --- | --- |
| 订舱 | Booking | 向船公司/货代订舱位，取得订舱确认（Booking Confirmation）。 |
| 拖车 / 内贸运输 | Trucking / Inland Transport | 从工厂/仓库把货拉到码头或堆场。 |
| 出口报关 | Customs Clearance (Export) | 向海关申报出口，取得放行。 |
| 装船 | Loading / On-board | 货物装上船舶。 |
| 海运 | Ocean Freight | 海上运输，凭提单（B/L）交接。 |
| 目的港清关 | Customs Clearance (Import) | 目的国进口申报。 |
| 目的港配送 | Delivery | 拖车/配送至最终收货人。 |

## 工程物流的链路特点

工程物流（项目货）的链路更复杂，通常还包含：

- **装卸 / 吊装**：Heavy Lift、特种吊装；
- **绑扎加固**：Lashing & Securing；
- **陆路超限运输**：大件公路运输的路线勘察与许可；
- **滚装（RORO）或散杂货船（Breakbulk）** 等非标准运输方式。

这些内容会在模块 03「工程物流核心」展开。

## 新人记忆要点

把链路拆成"**四段**"最容易记：

1. **国内段**：工厂 → 港口（拖车、内贸、报关）；
2. **干线段**：港口 → 港口（海运 / 空运 / 铁路）；
3. **目的段**：目的港 → 收货人（清关、配送）；
4. **增值段**：装卸、绑扎、加固、仓储、保险等。

> 货代的利润，来自对其中一段或多段的专业整合与议价能力。
