这是所有国际物流岗位的**通用地基**。无论做工程物流还是普通货代，都要先掌握国际贸易的通用语言和物流链路。

## 本模块你将学到

1. Incoterms 2020 贸易术语（FOB / CIF / EXW / DAP / DDP 等）；
2. 国际物流的全链路流程；
3. 基础单证（提单、箱单、发票、报关单等）；
4. 付款方式（T/T 与 L/C 信用证）基础。

## 为什么新人要先学这里

国际贸易术语和单证是**和客户、供应商对话的通用语言**。如果客户说"我们做 FOB 深圳"，你要立刻知道责任和费用边界在哪里、哪些环节由谁负责。
