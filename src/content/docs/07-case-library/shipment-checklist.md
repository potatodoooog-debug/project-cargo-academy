可复制本页清单到每票实操笔记，按阶段逐项打勾；各阶段规则细节直接点对应页面，不在本页重复展开。

## 1. 询盘接单

- [ ] 分清询盘性质：实货（firm）/ 投标（bidding）/ 预算（budgetary）
- [ ] 收齐中英文品名、件数、包装后实测 `L×W×H`、毛重、重心与照片 / Excel 装箱单
- [ ] 核清起运地、目的港、Incoterms、齐货时间及能否接受甲板配载
- [ ] 若像件杂货，同步补问是否可堆叠（stackable）与期望装卸条款；清单见 [询价反问清单](../05-sales-business/inquiry-checklist/) 与 [件杂货询盘与计费](../03-project-cargo/bbk-inquiry/)

## 2. 路径与合规预审

- [ ] 判断走标准柜、OT/FR 特种柜还是件杂船（尺寸接近临界先按超限问）
- [ ] 同查起运港、中转港、目的港三处吊重与船东重柜/特种柜政策（见 [特种柜 FR / OT / Platform](../03-project-cargo/special-containers/)）
- [ ] 排查是否含锂电池（UN 编号、SDS、UN38.3、SOC，资料不齐不订舱；见 [锂电池运输红线](../04-energy-storage/battery-dg-rules/)）
- [ ] 排查是否含 2 类气体或其他危险品/带磁/液体（见 [2 类危险品：气体](../01-trade-basics/dg-class-2/)）

## 3. 方案与分项报价

- [ ] 用五步结构向客户讲清方案选项、风险边界与下一步（见 [项目运输方案怎么讲](../03-project-cargo/solution-framing/)）
- [ ] 按分项结构核全成本项，不漏 killed slots、码头吊卸、绑扎与 OOG 堆存（见 [报价结构](../05-sales-business/quoting-structure/)）
- [ ] 明确方案有效期与假设条件（最终实测尺寸、船东最终确认权）
- [ ] 真实底价与内部测算仅留本地私密工作表，不外泄

## 4. 订舱交接

- [ ] 客户书面确认方案与最终包装实测数据后，再下正式订舱单
- [ ] 核对 `IG/OW/OH/OL` 备注、`panels up/down`、`under deck/on deck` 及装卸条款原文
- [ ] 危险品货物在订舱前完成全部合规文件预审
- [ ] 交接要点按 [订舱与执行交接清单](../05-sales-business/booking-handoff/) 逐条核过

## 5. 装货、绑扎与 VGM

- [ ] 提前确认工厂吊装条件、公路超限许可与车队车型（见 [绑扎加固与公路段](../03-project-cargo/lashing-and-road/)）
- [ ] 现场核对实测尺寸、重心与吊点未受遮挡，并留存装前/装后/绑扎后照片
- [ ] 集装箱与 OT/FR 按集装箱按时提交 VGM；件杂货按件提供重量（见 [集装箱类型](../02-freight-forwarding/containers/)）
- [ ] 盯紧免堆期与港区现场协调（见 [件杂港口操作](../03-project-cargo/port-ops/)）

## 6. 报关、装船与对单

- [ ] 核齐报关单、商业发票、装箱单及所需原产地证/检验文件（见 [基础单证](../01-trade-basics/documents/)）
- [ ] 逐字核对提单（区分船东单与货代单，确认运费条款与特殊批注）
- [ ] 若走信用证（L/C），严格对照条款审单防止不符点（见 [付款方式：T/T 与 L/C](../01-trade-basics/payment/)）
- [ ] 确认开航动态与目的港代理/清关交接

## 7. 到港交付与脱敏复盘

- [ ] 跟进目的港清关、查验、卸货及派送签收
- [ ] 真实运价、账单、毛利与客户联系人归档至本地私密工作库
- [ ] 将货型结构、路径决策、卡点与改进动作脱敏沉淀为本模块新案例
