> 公开库只留脱敏后的复盘结论；真实展商名录、联系人与报价单放本地私密库。

参展动作配合 [展会获客 SOP](../05-sales-business/exhibition-sop/) 执行；会后一周内用下面模板完成一次脱敏复盘，并把结论同步回 [展会日历](../08-resources/exhibitions/) 与 [行业英文术语表](../06-english-terms/glossary/)。

## 复制模板

```md
---
title: 展会复盘：[展会简称 + 城市 + 年份]
description: 一句话概括本次参展收获与次年建议。
---

## 基本信息

- 展会名称 / 城市 / 时间：
- 参展身份：（观众 / 展商 / 联合拜访）
- 核心目标：（如：锁定储能集成商 A 类线索 X 家 / 摸清某航线市场痛点）

## 结果数据（脱敏统计）

- 有效名片 / 微信数：
- 分级分布：A 类（有明确出货计划）___ / B 类（潜在适配）___ / C 类（长期触达）___
- 48 小时内跟进率：
- 会后 30 天内转正式询价数：

## 高价值发现

- 客户普遍卡点：（如：带电合规资料不清 / 目的港清关 / 超重超限判断）
- 热门航线与货型：（如：东南亚一体柜 / 欧洲多式联运）
- 常见高频问答或行业新词：

## 投入产出判断与明年建议

- 展商质量与专业度评价：
- 差旅与时间成本性价比：
- 明年是否再去：（⭐ 主攻 / ◎ 可选 / ✕ 不去，说明理由）

- [ ] 若产出典型路径讨论，脱敏后补一篇模式案例
```
