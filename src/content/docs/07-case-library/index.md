> 案例库是"学一点、补一点"的最佳落点。每跟进一票货、参加一次展会，就沉淀一篇。

## 规划内容

1. **项目复盘模板**：货物品名 / 尺寸重量 / 起运港目的港 / 运输方式 / 难点 / 教训；
2. **全流程 checklist**：从询价到交付的标准化检查清单；
3. **展会记录**：国内 / 东盟储能柜展会参会记录（见岗位说明书附录）。

## 建议模板（每篇案例固定结构）

```md
---
title: 案例：xxx
description: 一句话概括
sidebar:
  order: 1
---

## 货物信息
- 品名 / 尺寸 / 重量 / 数量
## 运输方案
- 起运港 → 目的港，运输方式，船期
## 难点与处理
## 复盘（做对了什么 / 下次改进什么）
```
