> 案例库是"学一点、补一点"的最佳落点。每跟进一票货、参加一次展会，就沉淀一篇。

## 规划内容

1. **项目复盘模板**：货物品名 / 尺寸重量 / 起运港目的港 / 运输方式 / 难点 / 教训；
2. [一票项目货全流程 Checklist](./shipment-checklist/)：从询价到交付的标准化检查清单；
3. [展会复盘模板](./exhibition-review-template/)：国内 / 东盟与行业展会的会后脱敏复盘骨架。
