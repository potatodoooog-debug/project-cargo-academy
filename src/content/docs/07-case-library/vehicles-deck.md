> 模式案例，不是某一票货。装港、卸港、件数和客户留到你自己的复盘里再写。

## 货物信息

- 品名 / 尺寸 / 重量 / 数量：车辆（小车或工程机械等）
- 积载：可以舱内也可以甲板

## 运输方案

- 起运港 → 目的港，运输方式，船期：滚装或件杂，按实票；**和集装箱不是同一套收货规则**
- 滚装操作见 [滚装与车辆](../03-project-cargo/roro/)

## 难点与处理

- 先确认车能不能自己开上下船
- 高度（含高顶车）与码头是否收该类型，订舱前确认

## 复盘（做对了什么 / 下次改进什么）

**风险：** 车不能自开、高度超限、码头不收。

**下次：** 不要用集装箱订舱习惯去套滚装舱位确认节奏。
