> 模式案例，不是某票货。不写装港、卸港、件数、客户、日期。

## 货物信息

- 品名 / 尺寸 / 重量 / 数量：卷钢，裸装
- 积载：舱底，要绑扎固定

## 运输方案

- 起运港 → 目的港，运输方式，船期：件杂路径；计费多按吨
- 计费与装卸条款见 [件杂询盘与计费](../03-project-cargo/bbk-inquiry/)；港口注意见 [件杂港口操作](../03-project-cargo/port-ops/)

## 难点与处理

- 裸装对绑扎和垫料要求高
- 目的港卸货条件直接影响破损与索赔风险

## 复盘（做对了什么 / 下次改进什么）

**风险：** 货损、目的港卸货条件差、利润薄所以方案空间小。

**下次：** 询盘阶段先问清卸港作业习惯；不要在方案阶段再改装卸条款口径。
