> 模式案例，不是某票货。不写装港、卸港、件数、客户、日期。

## 货物信息

- 品名 / 尺寸 / 重量 / 数量：框架柜路径，超宽（OW）加超高（OH）
- 装法：挡板竖起（panels up），货物放在中间以保重心

## 运输方案

- 起运港 → 目的港，运输方式，船期：特种柜 FR；具体港与船期按实票填
- 柜型与积载说明见 [特种柜](../03-project-cargo/special-containers/)

## 难点与处理

- 装货和绑扎要在现场看，不能只靠纸面尺寸
- 吊点是否被挡、能否用常规集装箱吊具，现场确认

## 复盘（做对了什么 / 下次改进什么）

**风险：** 吊点被挡、临时改成甲板、堆存（OOG 常常没有普柜那种免堆）。

**下次：** 报价备注写清 OW+OH；起运港/中转港/目的港吊重都要看。
