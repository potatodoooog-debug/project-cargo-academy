## 通用物流

| 英文 | 中文 |
| --- | --- |
| Freight Forwarder | 货运代理（货代） |
| Carrier | 承运人（船公司/航空公司） |
| Shipper | 发货人 |
| Consignee | 收货人 |
| Booking | 订舱 |
| Bill of Lading（B/L） | 提单 |
| Customs Clearance | 报关 / 清关 |
| Incoterms | 国际贸易术语 |
| FOB / CIF / EXW / DDP | 装运港船上交货 / 成本保险加运费 / 工厂交货 / 完税后交货 |
| FCA | 货交承运人。集装箱和多式联运常用，不等于 FOB。 |
| DPU | 指定地点卸货后交货。 |
| VGM | 集装箱核实总重。托运人提交后，才满足装船条件。 |

## 操作与报价

| 英文 | 中文 |
| --- | --- |
| killed slots | 被超限货占掉、不能再卖的邻箱位 |
| laycan | 受载期 |
| FLT（full liner terms） | 班轮条款，装卸都管 |
| FILO（free in, liner out） | 装不管、卸管 |
| FIO（free in, free out） | 装卸都不管 |
| FIOST（free in and out, stowed and trimmed） | 装卸、堆装、平舱都不管 |
| revenue ton | 计费吨 |
| chargeable weight | 计费重 |
| ULD | 航空集装器 |
| firm | 实货询盘 |
| bidding | 投标询盘 |
| budgetary | 预算询盘 |
| Pivot | 一块板的保底计费公斤数 |
| DGM report | 空运部分锂电编号另要的报告 |
| MWS（Marine Warranty Surveyor） | 海事担保检验师（通常受保险人委托审签高风险重大件操作） |
| GENCON | BIMCO 通用程租合同范本 |
| CONLINEBOOKING | BIMCO 班轮订舱单范本 |
| NOR（Notice of Readiness） | 装卸准备就绪通知书 |
| Laytime | 许可装卸时间 |
| Demurrage / Despatch | 滞期费 / 速遣费（集装箱场景下 D&D 常指滞港与滞箱费） |
| HLS / ELS | 超重附加费（Heavy Lift Surcharge）/ 超长附加费（Extra Length Surcharge） |
| Joint Survey | 联合检验（货方、保险方与承运人共同定损） |
| Notice of Protest | 抗议书 / 货损书面保留通知 |
| Hague-Visby Rules | 海牙-维斯比规则（提单下海运承运人责任与限额国际公约） |
