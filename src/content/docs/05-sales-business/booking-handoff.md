本页梳理从「报价确认」到「装船出单」的通用交接字段，不涉及具体公司抬头或真实运价。

## 1. 订舱单核心核对字段

| 类别 | 核对内容 | 常见防错点 |
|---|---|---|
| 当事人 | 发货人（Shipper）、收货人（Consignee）、通知方（Notify Party） | 与贸易合同、报关资料一致；若走信用证按 L/C 条款核对 |
| 航线与港序 | 起运港（POL）、目的港（POD）、最终目的地（若到门） | 确认中转港与目的港吊重是否匹配单件毛重 |
| 货物明细 | 中英文品名、件数、包装后毛重与尺码（`L×W×H`） | 与装箱单和实测一致，不按裸机预估填单 |
| 柜型与超限备注 | `20'OT / 40'OT / 20'FR / 40'FR` 及 `IG / OW / OH / OL` 组合 | 写明挡板竖起（`panels up`）或放下（`panels down`） |
| 配载与附件 | 舱内（`under deck`）或甲板（`on deck`）、帆布、绑扎、监装报告（`survey report`） | 客户能否接受甲板配载须提前书面确认 |
| 件杂条款 | 装卸条款（`FLT / FILO / FIO / FIOST` 等）与受载期（`laycan`） | 装卸条款以委托书原文为准，不凭简称口头推断 |

## 2. 危险品与敏感货前置闸门

- **锂电池与储能柜**：订舱前必须核齐最新版中英文 SDS/MSDS、UN38.3 报告、适运证明、危险品包装证明（若适用）及计划 SOC；**资料不齐暂停下订舱单**，不承诺先订舱后补件。详见 [锂电池运输红线](../04-energy-storage/battery-dg-rules/)。
- **2 类气体与其他危险品**：先核对准确 UN 编号及项别（2.1 / 2.2 / 2.3），按项别核齐单证并确认可接口岸，避免拼箱或空运踩雷。详见 [2 类危险品：气体](../01-trade-basics/dg-class-2/)。

## 3. 装货、绑扎与现场留证

- **现场实测核对**：复核实际包装后尺寸、重量、重心（COG）及四个吊点是否被遮挡（尤其 FR 挡板放下时两吊点之间宽度限制）。
- **留证照片**：至少留存**装前、装后、绑扎后**三组清晰照片（含箱号/车牌与吊点位置）；需要时按约定安排监装并出具监装报告（`survey report`）。
- **绑扎与公路衔接**：核对绑扎受力点、垫木与马鞍位置，公路超限车辆许可及厂区吊装条件同步对齐。细节见 [绑扎加固与公路段](../03-project-cargo/lashing-and-road/) 与 [特种柜 FR / OT / Platform](../03-project-cargo/special-containers/)。

## 4. VGM、截关与超限堆存

- **VGM 规则区分**：标准集装箱以及开顶柜（OT）、框架柜（FR）**按集装箱办理核实总重（VGM）**，须在截关/船公司截止时间前按要求提交，这是装船条件；件杂货按件提供重量，不使用集装箱 VGM 规则。详见 [集装箱类型](../02-freight-forwarding/containers/)。
- **超限堆存提醒**：提前书面提醒客户，OOG 特种柜常常没有普柜那种免堆期；件杂货的超期堆存由货主与码头结算，不找船公司。详见 [件杂港口操作](../03-project-cargo/port-ops/)。

## 5. 对单与出提单

- **区分提单类型**：明确这票出的是船东单（Ocean B/L）还是货代单（House B/L），以及正本（Original）还是电放/海运单方式。
- **逐字对单**：核对品名、件数、毛重、体积、唛头、运费条款（Freight Prepaid / Collect）及特殊批注（如 `on deck`）。
- **信用证单据审查**：若客户采用 L/C 付款，须严格对照信用证条款审核提单、发票、装箱单与相关证明，防止出现不符点导致拒付。详见 [基础单证](../01-trade-basics/documents/) 与 [付款方式：T/T 与 L/C](../01-trade-basics/payment/)。

## 6. 结算与复盘分流

- **敏感数据入私密库**：真实运价、成本明细、毛利测算、提成节点与客户/代理具体联系方式，全部记录在本地私密工作库，不进公开仓库。
- **通用经验入案例库**：这票走完后，把尺寸结构、配载难点、绑扎教训与沟通要点脱敏整理，按模板补进 [案例库](../07-case-library/)。

## 复述

框架柜与开顶柜按集装箱办理 VGM，件杂货按件提供重量。  
装货现场要核对实测包装尺寸、吊点是否被挡，并留存装前、装后、绑扎后照片。  
真实运价与客户信息记本地私密库，脱敏后的通用经验再写回公开案例库。

**复习题：** 框架柜（FR）装箱完成后，需不需要提交集装箱核实总重（VGM）？

答：需要。框架柜和开顶柜按集装箱办理 VGM；只有件杂货按件提供重量，不使用集装箱 VGM 规则。
