## 原则

1. **结构公开，数字私密** — 真实运价、客户名不要进公开 GitHub  
2. **先路径后价格** — 方案未定，价格无意义  
3. **分项 > 一口价** — 新人用分项学习，也方便和客户解释  

## 典型分项（集装箱特种柜路径）

| 分项 | 说明 |
|---|---|
| 起运地拖车 / 超限车 | 厂到堆场/码头 |
| 报关 / 查验 | 含文件服务 |
| 码头操作 / 打单 | 含超限作业可能 |
| 绑扎 / 加固 / 看货 | 材料+人工 |
| 海运费 | 基价 |
| OOG 附加 | 按超限与船东 |
| 特种柜租/用箱 | 视合约 |
| 保险 | 若代办 |
| 目的港费用 | 若到门或指定 |
| 利润与风险备用 | 内部，不对外拆太细 |

## 件杂路径额外常见项

- 港作吊装、驳运、待时  
- 按计费吨或包干的海运  
- 特殊绑扎与焊马鞍（若发生）  
- 船期等待导致的堆存  

## 对内测算（入职后向主管请教的口径）

- 「利润」扣哪些成本？坏账谁承担？  
- 提成节点：开航 / 到港 / 回款？  
- 亏损票是否倒扣？  

这些写进你的**私密**入职笔记，不进本公开库。

## 练习

用假想数字做一票：深圳 → 鹿特丹，1×40FR，OOG 轻微超宽。  
只要求分项结构完整，数字合理即可（学习用）。
