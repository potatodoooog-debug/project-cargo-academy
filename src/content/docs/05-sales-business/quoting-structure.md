## 原则

1. **结构公开，数字私密** — 真实运价、客户名不要进公开 GitHub  
2. **先路径后价格** — 方案未定，价格无意义  
3. **分项 > 一口价** — 新人用分项学习，也方便和客户解释  

## 典型分项（集装箱特种柜路径）

| 分项 | 说明 |
|---|---|
| 起运地拖车 / 超限车 | 厂到堆场/码头 |
| 报关 / 查验 | 含文件服务 |
| 码头操作 / 打单 | 含超限作业可能；码头吊卸 |
| 绑扎 / 加固 / 看货 | 材料+人工 |
| 海运费 | 基价 |
| OOG 附加 | 按超限与船东 |
| killed slots | 超限货占掉、不能再卖的邻箱位 |
| OOG 堆存 | 培训口径：OOG 常常没有普柜那种免堆 |
| 特种柜租/用箱 | 视合约 |
| 保险 | 若代办 |
| 目的港费用 | 若到门或指定 |
| 利润与风险备用 | 内部，不对外拆太细 |

起运港、中转港、目的港三处吊重都要看。结构细节见 [特种柜](../03-project-cargo/special-containers/)。

## 件杂路径额外常见项

- 港作吊装、驳运、待时
- 计费方式：按吨、按方（CBM）、包干（lump sum）
- 装卸条款（FLT / FILO / FIO / FIOST 等，以委托书为准）
- 特殊绑扎与焊马鞍（若发生）
- 船期等待导致的堆存

字段与条款人话见 [件杂询盘与计费](../03-project-cargo/bbk-inquiry/)。  

## 内部测算口径（仅记在本地私密笔记）

- 「利润」扣哪些成本？坏账谁承担？  
- 提成节点：开航 / 到港 / 回款？  
- 亏损票是否倒扣？  

这些写进本地私密工作库，不进本公开库。

## 复述

报价遵守「结构公开、数字私密」和「先路径后价格」，方案未定时报价无意义。  
特种柜报价结构要包含 killed slots、码头吊卸、OOG 堆存，并同时看起运港、中转港、目的港三处吊重。  
件杂路径还要写清计费方式（按吨、按方或包干）与装卸条款（以委托书原文为准）。

**复习题：** 特种柜的堆存成本为什么不能直接照搬普柜经验？

答：按本页培训口径，OOG 常常没有普柜那种免堆。

## 练习

用假想数字做一票：深圳 → 鹿特丹，1×40FR，OOG 轻微超宽。  
只要求分项结构完整，数字合理即可（学习用）。
