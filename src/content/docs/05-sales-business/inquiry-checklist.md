复制到笔记，每票货勾选。

## A. 货物

- [ ] 准确品名（中英文）  
- [ ] 件数；是否可拆、可叠  
- [ ] 每件 L×W×H（含包装），单位 cm/m 统一  
- [ ] 每件毛重；总重；重心资料  
- [ ] 包装形式；照片/图纸  
- [ ] 是否危险品 / 含锂电池 / 带油带电带磁  

## B. 路径与节点

- [ ] 起运地（工厂地址）  
- [ ] 装港偏好；是否指定船东  
- [ ] 目的港；是否到门；最终工地地址  
- [ ] 齐货日期；要求开航/到港日期  
- [ ] Incoterms（成交方式）  

## C. 服务范围

- [ ] 是否含国内段拖车/报关/内装绑扎  
- [ ] 是否含海运保险  
- [ ] 是否含目的港清关/派送  
- [ ] 是否需要现场查勘  

## D. 合规（储能/电池加强）

- [ ] UN 编号与 DG 文件能否提供  
- [ ] SDS、UN38.3 等  
- [ ] SOC 是否可调  

## E. 商务

- [ ] 付款方式与账期预期  
- [ ] 是否招标；是否只要参考价  
- [ ] 决策人是谁；项目名称（便于归档）  

## 第一封确认邮件结构

1. 感谢询价 + 复述已知  
2. 列出**缺失项**（用清单）  
3. 说明补齐后可提供的产出（路径建议 / 正式报价）  
4. 给出你的时间承诺（如 1–2 个工作日）
