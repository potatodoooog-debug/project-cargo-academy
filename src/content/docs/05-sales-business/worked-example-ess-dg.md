这是一票**虚构货**，用来练习在「储能 + 锂电 DG + 疑似超重/超限」场景下翻查站内页面，不是案例库里的实票。本页不报价，不新增任何未经核对的法规数字。

## 已知

- 1 台集装箱式一体柜储能系统（含锂离子电池）
- 客户只说「外观跟 20 尺柜差不多，下周要出雅加达，先帮我订舱」
- 没有提供 UN 编号、没有 SDS/MSDS、没有 UN38.3、没有 SOC、没有最终包装后精确尺寸和毛重、没有吊点图、没有贸易术语（Incoterms）

## 1. 先停在锂电池红线

打开 [锂电池运输红线](../04-energy-storage/battery-dg-rules/)。

- 只要设备含锂电池，海运通常按**危险货物（DG）** 管理。**资料不齐不订舱、不承诺下周船期死价**——销售个人不能承诺「先出运再补文件」。
- 先核实具体 UN 编号（例如单独运输常见 UN3480，在设备里或与设备一起常见 UN3481，或其他适用编号）；最终分类、包装说明与是否允许集装箱装运，必须由**合格 DG 人员/代理和船东书面确认**。

## 2. 拆开要两类缺失资料

结合 [储能产品与物流视角](../04-energy-storage/product-basics/) 与 [询价反问清单](./inquiry-checklist/)，分两组向客户要齐缺失项：

**A. 货物与路径项**

- 最终包装后的实测长宽高（`L×W×H`）
- 单件毛重与重心（COG）资料
- 吊点 / 叉车位图纸（及是否可整体吊装、是否可堆叠）
- 起运工厂地址
- 贸易术语（Incoterms）及是否需要门到门 / 目的港派送
- 询盘性质：实货（firm）、投标（bidding）还是预算（budgetary）

**B. DG 合规项**

- 准确 UN 编号、正确运输名称（Proper Shipping Name）与类别/项别
- 最新版中英文 SDS / MSDS
- UN38.3 测试报告
- 适运证明（海运）
- 危险品包装证明（若适用；按红线页培训矩阵，UN3480 海运明确勾选此项，具体以合格 DG 代理与船东确认为准）
- 当前计划 SOC（荷电状态），以及是否可按船东书面要求调整

## 3. 识别「OOG/重件 + DG」双标签

翻看 [储能产品与物流视角](../04-energy-storage/product-basics/) 与 [特种柜 FR / OT / Platform](../03-project-cargo/special-containers/)：

- **外观接近 20' 集装箱 ≠ 可按普通货柜订舱**：电池能量密度常带来明显超重，必须核对柜门载重、船公司重柜政策，并同时看**起运港、中转港、目的港**三处吊重；若带包装或附件超限，还要同步评估特种柜（OT/FR）或件杂路径。
- **核对出运形态备选**：向客户确认本票是必须整柜带电出运，还是存在空预制舱体与电池分开运输的备选方案（两者的船东准入和单证压力不同）。
- **起运口岸初判**：参考红线页口岸口径（会变，不是推荐订舱地；订舱前必须向船东及 DG 代理书面确认实际可接口岸与船期）。

## 4. 报价只列结构（不写数字）

按 [报价结构](./quoting-structure/) 梳理分项结构（每个分项数字不在本站）：

- 起运地拖车 / 超限车（工厂到堆场/码头）
- 报关与 DG 危险品申报
- 码头操作与吊卸（含超限/重件作业可能）
- 绑扎加固与现场看货
- 海运基价
- DG 附加与 OOG 附加（若走特种柜，含可能的 killed slots）
- 超限 / DG 堆存（OOG 常常没有普柜免堆）
- 目的港清关、查验与派送（按 Incoterms 边界）
- 保险（若代办）

## 5. 第一封回复怎么发

结合 [目标市场与认证直觉](../04-energy-storage/markets-certs/) 与 [商务英文邮件模板](../06-english-terms/email-templates/)：

- 绝不回「好的已订」，而是套用「模板 2（询价资料不全反问）+ 模板 5（危险品合规闸门）」发送缺失资料清单。
- 明确管理期望：收到最终包装尺寸、毛重与 DG 基础文件后，先核查船东与口岸可行性，再在约定工作日内提供初步路径建议；资料未齐前不锁定下周船期与运价。

## 复述

含锂电池储能柜资料不齐时，只收资料，不订舱、不承诺死期死价。  
外观像 20 尺集装箱不等于普柜，要按「OOG/重件 + DG」双流程同时评估。  
最终分类、单证组合与起运口岸以合格 DG 代理和船东书面确认为准。

**复习题：** 客户催你「下周必须出印尼，先订舱，文件后补」，按本页和红线页口径该如何处理？
